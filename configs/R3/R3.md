---

## 1. Executive Summary & Architecture

Router **R3** is the central **Route Reflector (RR)** and core **Autonomous System Border Router (ASBR)** for **AS 2121**:

1. **iBGP / MP-VPNv4 Route Reflector:** Reflects IPv4, VPNv4, and IPv6 routes to clients **R1**, **R2**, and **R4**.
2. **eBGP Peering with AS 2122:** Establishes eBGP (IPv4/IPv6) sessions with external router **ASBR-2122**. Applique `PREFER-2122-IN` route map (`local-preference 200`) to prefer routes learned via AS 2122.
3. **OSPF Area Border Router (ABR):** Connects Area 0 (Backbone) with Area 1, hosting a Virtual Link to R1 (`121.0.0.1`).
4. **MPLS Core Routing:** Runs LDP on internal links to support L3VPN label switching across AS 2121.

## 3. Routing & BGP / Route Map Configuration

### 3.1. OSPF Configuration
- **Process ID:** `1` | **Router ID:** `121.0.0.3`
- **Area 1:** Virtual Link with `121.0.0.1` (R1).
- **Networks:** Area 0 (`121.0.0.3/32`, `121.1.0.8/30`), Area 1 (`121.1.0.0/30`).

### 3.2. BGP / MP-BGP Configuration (AS 2121)
- **Route Reflector Clients (IPv4 & VPNv4):** `121.0.0.1` (R1), `121.0.0.2` (R2), `121.0.0.4` (R4).
- **eBGP Neighbor:** `121.1.0.14` (AS 2122 IPv4) and `2123:4561:0:4::2` (AS 2122 IPv6).
- **Traffic Engineering:** Route-map `PREFER-2122-IN` applies `set local-preference 200` for inbound prefixes from AS 2122.
