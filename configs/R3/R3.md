# Documentação de Configuração - Roteador R3

**Dispositivo:** R3  
**Versão do IOS:** Cisco IOS 15.2  
**Data da Última Alteração:** 16 de Setembro de 2026, 02:12:40 UTC  
**Função na Rede:** Route Reflector (RR) / Area Border Router (ABR) / Autonomous System Border Router (ASBR)  
**Sistema Autónomo (AS):** 2121  

---

## 1. Resumo Executivo e Arquitetura

O roteador **R3** é um elemento central na arquitetura da rede do **AS 2121**, desempenhando três papéis críticos simultaneamente:

1. **Route Reflector (RR) iBGP / MP-BGP:** Atua como o refletor de rotas central para os roteadores R1, R2 e R4 nas famílias de endereços IPv4, VPNv4 (L3VPN) e IPv6, eliminando a necessidade de uma malha total (*full-mesh*) iBGP.
2. **Area Border Router (ABR):** Interliga a **Área 0 (Backbone)** e a **Área 1** no OSPF/OSPFv3, mantendo o *Virtual-Link* ativo com o R1 (`121.0.0.1`).
3. **Autonomous System Border Router (ASBR):** Estabelece sessões eBGP (IPv4 e IPv6) com o Sistema Autónomo vizinho **AS 2122**, definindo políticas de preferência local (*Local Preference*) para o tráfego de entrada.

## 4. BGP / MP-BGP (AS 2121) e Políticas de Roteamento

### 4.1. Função de Route Reflector (iBGP)
O R3 está configurado como **Route Reflector** para todos os roteadores internos da rede:

| Cliente RR | Endereço IPv4 | Endereço IPv6 | Famílias Ativas | Configurações Especiais |
| :--- | :--- | :--- | :--- | :--- |
| **R1** | `121.0.0.1` | `2123:4561:0:F::1` | IPv4, VPNv4, IPv6 | `route-reflector-client`, `next-hop-self`, `send-community extended` |
| **R2** | `121.0.0.2` | `2123:4561:0:F::2` | IPv4, VPNv4, IPv6 | `route-reflector-client`, `next-hop-self`, `send-community extended` |
| **R4** | `121.0.0.4` | `2123:4561:0:F::4` | IPv4, IPv6 | `route-reflector-client`, `next-hop-self` (IPv4) |

### 4.2. Conectividade Exterior eBGP (AS 2122)
- **Vizinho IPv4:** `121.1.0.14` (AS 2122)
- **Vizinho IPv6:** `2123:4561:0:4::2` (AS 2122)
- **Anúncios de Redes:**
  - IPv4: `121.0.0.1/32`
  - IPv6: `2123:4561:0:1::/64`

### 4.3. Política de Tráfego de Entrada (`PREFER-2122-IN`)
Aplicada na recepção de rotas do AS 2122 (tanto IPv4 como IPv6):
```cisco
route-map PREFER-2122-IN permit 10
 set local-preference 200
```
- **Efeito:** Aumenta o valor de *Local Preference* de `100` (padrão) para `200` para todas as rotas recebidas do AS 2122, garantindo que o tráfego do AS 2121 prefira sair por este enlace para atingir esses destinos.

## 5. Configuração MPLS e Serviços de Infraestrutura

- **Protocolo de Etiquetagem:** MPLS LDP (`mpls label protocol ldp`).
- **LDP Router ID:** `Loopback0` (com opção `force`).
- **Interfaces MPLS Ativas:**
  - `FastEthernet0/0` (Link para R1)
  - `FastEthernet1/0` (Link para R4)
- **Parâmetros de Segurança e Gestão:**
  - Desativação de pesquisas DNS (`no ip domain lookup`).
  - Ativação do Cisco Express Forwarding (`ip cef`, `ipv6 cef`).
  - Encaminhamento IPv6 Unicast ativo (`ipv6 unicast-routing`).
  - Desativação de servidores web HTTP/HTTPS.
  - Controlo de acesso e logging síncrono nas linhas `con 0`, `aux 0` e `vty 0 4`.
