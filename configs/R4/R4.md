# Documentação de Configuração - Roteador R4

**Dispositivo:** R4  
**Versão do IOS:** Cisco IOS 15.2  
**Data da Última Alteração:** 16 de Setembro de 2026, 00:50:45 UTC  
**Função na Rede:** ASBR (Autonomous System Border Router) / Cliente de Route Reflector (RR)  
**Sistema Autónomo (AS):** 2121  

---

## 1. Resumo Executivo e Arquitetura

O roteador **R4** atua como um roteador de borda do **AS 2121**, com as seguintes responsabilidades principais:

1. **ASBR (Autonomous System Border Router):** Estabelece sessões eBGP (IPv4 e IPv6) com o Sistema Autónomo vizinho **AS 2123**.
2. **Cliente de Route Reflector (iBGP):** Mantém sessões iBGP/MP-BGP exclusivamente com o refletor de rotas **R3** (`121.0.0.3` / `2123:4561:0:F::3`), através do qual recebe e envia a informação de roteamento do AS 2121.
3. **Roteamento Interno OSPF (Área 0):** Pertence integralmente à **Área 0 (Backbone)** do OSPFv2 e OSPFv3.
4. **Engenharia de Tráfego de Saída (*AS-Path Prepending*):** Aplica uma política de saída no eBGP para desincentivar o tráfego do AS 2123 através deste enlace.

## 3. Protocolos de Roteamento Interno (IGP: OSPFv2 / OSPFv3)

- **Process ID:** `1`
- **Router ID:** `121.0.0.4`
- **Áreas Configuradas:**
  - **Área 0 (Backbone):** `Loopback0` (`121.0.0.4/32`) e enlace com R3 (`121.1.0.8/30`).
- **Interfaces Passivas:** `Loopback0`.
- **OSPFv3 (IPv6):** Ativado com o `router-id 121.0.0.4`.

---

## 4. BGP / MP-BGP (AS 2121) e Políticas de Roteamento

### 4.1. Sessões iBGP (Cliente de Route Reflector R3)
O R4 estabelece sessões iBGP apenas com o **R3** (Route Reflector):

| Vizinho | Endereço IP | AS Remoto | Famílias Ativas | Configurações Especiais |
| :--- | :--- | :--- | :--- | :--- |
| **R3 (IPv4)** | `121.0.0.3` | 2121 | IPv4 | `update-source Loopback0`, `next-hop-self` |
| **R3 (IPv6)** | `2123:4561:0:F::3` | 2121 | IPv6 | `update-source Loopback0` |

### 4.2. Conectividade Exterior eBGP (AS 2123)
- **Vizinho IPv4:** `121.1.0.18` (AS 2123)
- **Vizinho IPv6:** `2123:4561:0:5::2` (AS 2123)

### 4.3. Política de Engenharia de Tráfego (`PREPEND-OUT`)
Aplicada no envio de atualizações BGP para o AS 2123 ( IPv4 e IPv6):
```cisco
route-map PREPEND-OUT permit 10
 set as-path prepend 2121 2121 2121
```
- **Efeito:** Adiciona o número do próprio Sistema Autónomo (`2121`) três vezes adicionais no cabeçalho *AS-Path* das rotas anunciadas ao AS 2123. Isto torna o caminho através do R4 artificialmente mais longo e menos atrativo para o AS 2123, desencorajando o tráfego vindo dessa rede.

## 5. Configuração MPLS e Serviços de Infraestrutura

- **Protocolo de Etiquetagem:** MPLS LDP (`mpls label protocol ldp`).
- **LDP Router ID:** `Loopback0` (forçado com a opção `force`).
- **Interface MPLS Ativa:**
  - `FastEthernet0/0` (Link para o R3).
- **Serviços Globais e Segurança:**
  - Desativação de resolução de nomes DNS (`no ip domain lookup`).
  - Ativação do encaminhamento expresso de pacotes (`ip cef`, `ipv6 cef`).
  - Roteamento Unicast IPv6 ativado (`ipv6 unicast-routing`).
  - Servidores HTTP e HTTPS desativados (`no ip http server`, `no ip http secure-server`).
  - Configuração de acesso direto por consola (`con 0`), auxiliar (`aux 0`) e linhas de terminal virtual (`vty 0 4`).
