# Documentação de Configuração - Roteador R1

**Dispositivo:** R1  
**Versão do IOS:** Cisco IOS 15.2  
**Data da Última Alteração:** 16 de Setembro de 2026, 02:16:27 UTC  
**Função na Rede:** Provider Edge (PE) / Area Border Router (ABR)  
**Sistema Autónomo (AS):** 2121  

---

## 1. Resumo Executivo e Arquitetura

O roteador **R1** atua como **Provider Edge (PE)** na infraestrutura do AS 2121, oferecendo serviços de conectividade L3VPN para clientes empresariais (VRF `ENTERPRISE`) e interligação de áreas OSPF/OSPFv3.

### Principais Funcionalidades Ativas:
- **Encaminhamento L3VPN / MPLS:** Utilização de MPLS LDP e MP-BGP (VPNv4) para isolamento do cliente empresarial na VRF `ENTERPRISE`.
- **Roteamento IPv4 / IPv6 Multiarea:** OSPFv2 e OSPFv3 ativos na Área 1 e Área 2 (Stub), com *Virtual-Link* estabelecido através da Área 1 até ao router `121.0.0.3`.
- **Qualidade de Serviço (QoS - MQC):** Classificação e marcação de tráfego de entrada na interface CE (`FastEthernet1/1`) com base no tipo de aplicação (Voz, Dados Críticos, Dados Gerais) e escalonamento de saída (*Priority Queueing / Fair-Queueing*) na interface core (`FastEthernet0/0`).
- **BGP Multi-Family:** Suporte para IPv4 Unicast, VPNv4 Unicast, IPv6 Unicast e eBGP para o cliente (AS 65010).

## 4. Política de Qualidade de Serviço (QoS)

A arquitetura QoS do R1 utiliza a estrutura MQC (*Modular QoS CLI*) dividida em duas fases: marcação na entrada (Ingress) e priorização na saída (Egress).

### 4.1. Marcação na Entrada (Ingress Policy: `ENTRY-MARK`)
Aplicada na interface `FastEthernet1/1` (VRF `ENTERPRISE`):

| Classe | Critério de Emparelhamento | Ação (IP Precedence) |
| :--- | :--- | :--- |
| **VOICE** | Protocolo VoIP (`vofr`) | Set IP Precedence `5` (Critical/Voice) |
| **CRITICAL-DATA** | Protocolos `dns`, `icmp` | Set IP Precedence `4` (Flash Override) |
| **GENERAL-DATA** | Protocolos `http`, `ftp` | Set IP Precedence `1` (Priority) |
| **class-default** | Restante Tráfego | Set IP Precedence `0` (Routine) |

### 4.2. Escalonamento na Saída (Egress Policy: `OUT-TRAFFIC`)
Aplicada na interface `FastEthernet0/0` (Link para R3):

| Classe | Critério de Seleção | Mecanismo de Fila | Largura de Banda / Regra |
| :--- | :--- | :--- | :--- |
| **GOLD** | `ip precedence 5` | LLQ (Low Latency Queue) | Priority `10%` |
| **SILVER** | `ip precedence 4` | CBWFQ | Priority `30%` |
| **BRONZE** | `ip precedence 1` | CBWFQ | Priority `20%` |
| **class-default** | Tráfego Padrão | WFQ | `fair-queue` |

## 5. Protocolos de Roteamento

### 5.1. OSPFv2 (IPv4) & OSPFv3 (IPv6)
- **Process ID:** `1`
- **Router ID:** `121.0.0.1`
- **Áreas Configuradas:**
  - **Área 1:** Áreas do Core (`Loopback0`, `FastEthernet0/0`).
  - **Área 2:** Configurada como área **Stub** (`FastEthernet1/0`).
- **Virtual Link:** `area 1 virtual-link 121.0.0.3` (Estabelece adjacência lógica para a Área 0 com o R3).
- **Interfaces Passivas:** `Loopback0` (IPv4).

### 5.2. BGP / MP-BGP (AS 2121)
- **Router ID / Source:** `Loopback0`
- **Sessões iBGP Ativas:**
  - `121.0.0.3` (IPv4 / VPNv4)
  - `2123:4561:0:F::3` (IPv6)
- **Aplicações BGP Ativas:**
  - **Address-Family IPv4:** Peering com `121.0.0.3`.
  - **Address-Family VPNv4:** Peering com `121.0.0.3` com troca de comunidades estendidas (`send-community extended`).
  - **Address-Family IPv6:** Anúncio da rede `2123:4561:0:F::1/128`.
  - **Address-Family IPv4 VRF ENTERPRISE:** Peering eBGP com CE (`192.168.100.2`, AS 65010).

## 6. Configuração do MPLS e Parâmetros do Sistema

- **Protocolo de Sinalização de Etiquetas:** MPLS LDP (`mpls label protocol ldp`).
- **LDP Router ID:** `Loopback0` (com opção `force`).
- **Interfaces MPLS Habilitadas:**
  - `FastEthernet0/0` (`mpls ip`)
  - `FastEthernet1/0` (`mpls ip`)
- **Configurações de Segurança e Gestão:**
  - Desativação de pesquisas DNS (`no ip domain lookup`).
  - Ativação de Cisco Express Forwarding (`ip cef`, `ipv6 cef`).
  - Desativação de servidor HTTP (`no ip http server`, `no ip http secure-server`).
  - Desativação do envio de mensagens ICMP unreachable (`no ip icmp rate-limit unreachable`).
  - Nível de privilégio 15 nas linhas de consola e auxiliar.
