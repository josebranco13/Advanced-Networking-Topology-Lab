**Autonomous System (AS):** 2121  

---

## 1. Executive Summary & Architecture

Router **R1** is a critical **Provider Edge (PE)** device within **AS 2121**, performing multi-role routing and traffic conditioning functions:

1. **MPLS L3VPN Provider Edge (PE):** Houses the `ENTERPRISE` VRF (`RD 2121:1`, `RT 2121:999`), connecting to Customer Edge router **CE-HQ** via eBGP.
2. **OSPF Area Border Router (ABR):** Participates in OSPF Area 1 and Area 2 (configured as a Stub area), establishing a Virtual Link in Area 1 to maintain backbone connectivity with R3 (`121.0.0.3`).
3. **iBGP & MP-BGP Peering:** Establishes iBGP/MP-BGP (VPNv4, IPv4, IPv6) sessions with Route Reflector **R3**.
4. **QoS Traffic Conditioning:** Implements classification and policy maps (`ENTRY-MARK` and `OUT-TRAFFIC`) on customer and WAN interfaces for IP Precedence-based traffic prioritization (Voice, Critical Data, General Data).

## 3. Routing & MPLS / QoS Configuration

### 3.1. OSPF Configuration (IPv4 & IPv6)
- **Process ID:** `1` | **Router ID:** `121.0.0.1`
- **Area 1:** Virtual Link with `121.0.0.3` (R3).
- **Area 2:** Configured as a **Stub Area**.
- **Passive Interface:** `Loopback0`.

### 3.2. BGP / MP-BGP Configuration (AS 2121)
- **iBGP Peer:** `121.0.0.3` (R3 - Route Reflector) for IPv4 Unicast and VPNv4 (`send-community extended`).
- **IPv6 iBGP Peer:** `2123:4561:0:F::3` (R3).
- **VRF `ENTERPRISE` eBGP Peer:** `192.168.100.2` (CE-HQ, AS 65010).

### 3.3. VRF & QoS Policies
- **VRF `ENTERPRISE`:** RD `2121:1`, Export/Import RT `2121:999`.
- **Classification (`ENTRY-MARK` on Fa1/1):**
  - Voice -> IP Precedence 5
  - Critical Data (DNS, ICMP) -> IP Precedence 4
  - General Data (HTTP, FTP) -> IP Precedence 1
  - Default -> IP Precedence 0
- **Egress Policy (`OUT-TRAFFIC` on Fa0/0):** Priority queues for Gold (10%), Silver (30%), Bronze (20%), and Fair-Queue for default.

## 4. Infrastructure Services & Management

- **CEF & MPLS:** `ip cef`, `ipv6 cef`, `mpls label protocol ldp`, `mpls ldp router-id Loopback0 force`.
- **IPv6 Unicast Routing:** Enabled (`ipv6 unicast-routing`).
- **Management & Security:** Disabled DNS lookup, HTTP/HTTPS servers deactivated, exec-timeout set to 0, level 15 privilege on Console/Aux/VTY.
